# SOP-03 — Load Management

## 1. Anomaly threshold
A feeder reading 25% or more above its 7-day baseline is a load anomaly.
Two consecutive anomalous readings trigger a field inspection.

## 2. Investigation
Check for large new loads, sensor faults, and upstream switching before
declaring an overload. Never de-energize a feeder on telemetry alone.

## 3. Rolling blackouts
If system load exceeds safe capacity, rolling blackouts are the last
resort. They always require human confirmation and must spare feeders
serving hospitals and water plants wherever possible.

## 4. Recording
Log every load-shedding action with feeder, megawatts shed, duration, and
the confirming operator's name.
